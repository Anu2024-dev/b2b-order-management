# 5–7 Minute Live Demonstration Script
## Arrowstack Internship — Project 1: B2B Order Management Platform

---

## 1. Demo Prerequisites & Pre-Flight Checks

Before presenting to your mentor or evaluators:
1. Ensure PostgreSQL is running (`127.0.0.1:5433`).
2. Start the Backend API:
   ```bash
   cd server && npm start
   ```
   (Verify: `http://localhost:5000/api/v1/health` returns `{"status": "UP"}`)
3. Start the Frontend Client:
   ```bash
   cd client && npm run dev
   ```
   (Open browser at: `http://localhost:5173`)
4. Have the evaluation credentials ready:
   - **Customer**: `purchasing@apexsolutions.example.com` / `CustomerSecure#2026`
   - **Admin**: `admin@arrowdistributors.example.com` / `AdminSecurePass#2026`

---

## 2. Timed Demonstration Walkthrough

### Part 1: Introduction & Catalog Exploration (1.5 Minutes)
1. **Landing Page**: Navigate to `http://localhost:5173/catalog`.
   - *Talking Point*: "This is the commercial catalog for Arrowstack Apex Distribution. Products feature industrial SKUs, real-time stock levels, category filters, and search capabilities."
2. **Search & Filter**:
   - Type `"Sensor"` into search bar & click **Filter**. Show how photoelectric sensors filter dynamically.
   - Filter by Category `"Safety & PPE Equipment"`. Show helmets and gloves with stock statuses.
3. **Product Details**:
   - Click on `"ANSI Type II Industrial Safety Helmet"`. Point out technical specifications and stock notice.

---

### Part 2: Customer Ordering & Checkout Workflow (2 Minutes)
1. **Login as Customer**:
   - Navigate to `/login`. Click the **"Demo Customer"** quick-fill button, then click **"Sign In to Portal"**.
2. **Adding to Cart**:
   - Go to `/catalog`. On `"Cut Level 5 Kevlar Reinforced Nitrile Coated Work Gloves"`, select quantity `3` and click **"Add to Cart"**.
   - Notice the navbar badge updates to show `3` items.
3. **Cart Review**:
   - Navigate to `/cart`.
   - *Talking Point*: "All pricing, subtotals, and the 18% standard GST are calculated authoritatively by the backend server from PostgreSQL rows. Tampered client prices are completely ignored."
4. **Placing Purchase Order**:
   - Click **"Proceed to Review & Order"**.
   - Review destination facility address, enter note: `"PO-Q4-KODNEST-001"`, and click **"Place Official B2B Order"**.
   - *Talking Point*: "This submission executes an atomic PostgreSQL transaction with row locks on product items, deducting warehouse stock and generating a formal order and invoice simultaneously."
5. **Confirmation & Invoicing**:
   - Show the Order Confirmation page displaying the order number and invoice reference.
   - Click **"View & Print Commercial Invoice"**.
   - Demonstrate the formatted Tax Invoice and click **"Download PDF"** to display the binary PDF stream generated by `pdfkit`.

---

### Part 3: Administrator Operations & Fulfillment (2 Minutes)
1. **Switch to Administrator Session**:
   - Click **"Logout"**, go to `/login`, click the **"Admin Officer"** button, and sign in.
   - Notice the administrative navbar displays: Dashboard, Inventory Items, Categories, Stock Logs, All Orders, Users, Audit Logs, and Reports.
2. **Real-Time Dashboard**:
   - Highlight live metrics: Active Products, B2B Customers, Total Orders, and Gross Order Value.
   - Point out the low-stock inventory table showing real database rows.
3. **Advancing Order Status**:
   - Click on **"All Orders"** (Fulfillment Queue).
   - Locate the customer order placed moments ago (status: `PENDING`).
   - Click **"Advance Status"** &rarr; Select `CONFIRMED` &rarr; Click **"Apply Lifecycle Transition"**.
   - *Talking Point*: "The backend enforces a strict status lifecycle (`PENDING &rarr; CONFIRMED &rarr; PROCESSING &rarr; SHIPPED &rarr; DELIVERED`). Invalid skips are blocked."
4. **Stock Cancellation Rule (Edge Case Demonstration)**:
   - For an order in `PENDING` or `CONFIRMED`, choose `CANCELLED`.
   - Point out to the mentor that cancelling an order triggers an automatic database transaction restoring the exact deducted quantities back to the product ledger.

---

### Part 4: Compliance Audit Logs & Security Boundary (1.5 Minutes)
1. **Audit Logs**:
   - Navigate to `/admin/audit-logs`.
   - Point out the append-only ledger entries recording the `USER_LOGIN`, `ORDER_PLACED`, and `ORDER_STATUS_UPDATED` actions with actor timestamps and JSON metadata.
2. **Security & RBAC Proof**:
   - Open browser DevTools or an Incognito window.
   - Navigate directly to `http://localhost:5173/admin/dashboard` without logging in.
   - Show that the frontend redirects to `/login` and the backend returns HTTP `401 Unauthorized`.
   - Log in as customer and attempt to access `/api/v1/admin/dashboard`. Show HTTP `403 Forbidden` response.
